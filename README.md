# App Obra — versões para Windows

Este repositório guarda só os instaladores do App Obra para Windows (`Obra-Setup-<versão>.exe`) e os arquivos que a
versão instalada usa para se atualizar sozinha (`latest.yml` e `.blockmap`). O código-fonte não fica aqui.

**Para instalar:** abra [Releases](https://github.com/App-OBRA/obra-releases/releases/latest), baixe o
`Obra-Setup-<versão>.exe` e abra o arquivo. Depois disso, o Obra se atualiza sozinho.

As releases são publicadas automaticamente pelo workflow de release do repositório principal. Não publique à mão.
